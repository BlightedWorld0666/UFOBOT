04 / ACCESS CONTROL

Encrypted credentials vault

Save integration keys in private, server-side storage. Secret values cannot be read back through this interface.

SERVER-SIDE AES-256-GCM

The Hub and bot runtime do not automatically read these encrypted entries yet. The health integration can use the locally stored Hub API key.

Security model

  • Never stored in public website source or JavaScript
  • Encrypted on the server before writing to disk
  • Masked credentials with explicit replacement or removal
  • Use a private tunnel or access gateway for remote administration
